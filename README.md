# Procurement Spend Analysis

This project analyzes procurement spending data using Python to identify supplier patterns, category contributions, seasonal trends, buyer profiles, outliers, and cost relationships.

## Project Objective

The goal of this project is to turn raw procurement data into useful business insights that can support better purchasing decisions, supplier evaluation, and cost control.

## Main Questions

- Which suppliers account for the largest share of spending?
- Which procurement categories contribute most to total cost?
- Are there seasonal patterns in purchasing activity?
- Which buyers are responsible for the highest spending?
- Are there unusual transactions or outliers?
- What is the relationship between unit price, quantity, and total cost?

## Tools Used

- Python
- pandas
- NumPy
- Matplotlib
- SciPy
- Excel

## Analysis Performed

- Data cleaning and preparation
- Supplier spend analysis
- Category contribution analysis
- Monthly and seasonal trend analysis
- Buyer-level spending analysis
- Outlier detection
- Relationship analysis between quantity, unit price, and total cost
- Business interpretation of results
